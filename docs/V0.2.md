# v0.2 acceptance contract

v0.2 makes Agent Harness Index safe to use as an evidence layer before any public leaderboard or routing integration exists.

## Added guarantees

### Dataset integrity

A dataset is invalid when it contains:

- duplicate `run_id` values;
- duplicate stochastic trial identities for the same benchmark/version, task, trial, model/version, harness/version and configuration fingerprint.

The dataset fingerprint is independent of JSONL row order and changes when normalized observation content changes.

### Matched comparison

A comparison accepts exactly one model/harness/configuration cell on each side and requires the same benchmark identity/version. Trials are paired on benchmark + benchmark version + task ID + trial index.

The report includes:

- matched trial count and matched-set SHA-256;
- left-only and right-only coverage;
- left/right success rates and delta;
- win/loss/tie counts;
- paired mean deltas for cost, latency, input tokens and output tokens where both values are observed.

Missing telemetry is excluded from paired metric deltas rather than coerced to zero.

## Interpretation boundary

`ahi.comparison/v1` is descriptive. It does not claim statistical significance, causal harness superiority, or universal model quality. A future statistical layer may add tests only when the experimental design justifies them.

## Cloud-only acceptance

The following are fully testable in GitHub Actions and belong in normal CI:

- schema parsing;
- duplicate detection;
- content fingerprint determinism;
- single-cell enforcement;
- benchmark identity enforcement;
- matched coverage accounting;
- paired metric calculations.

Real Codex/OmO/DSH/Claude observations remain outside this acceptance contract because they depend on installed runtimes and credentials.
